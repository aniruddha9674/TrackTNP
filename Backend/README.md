# Running Backend Code

1. After clonning or downloading the branch and navigating inside the Backend folder.
2. Run the below commands.
   ```bash
   npm install
   ```
3. Run the project using below command
   ```bash
   npm run dev
   ```

4. After that create .env file inside frontend folder and enter the following line of code into it
   ```bash
   PORT=5000
   MONGO_URI=mongodb://127.0.0.1:27017/testdatabase
   ```

## Note: instead of testdatabase your can enter the desired database you want
